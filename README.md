  CEROTOUCH LAUNCHER
  Un launcher de Minecraft con estilo propio
==============================================================


QUÉ ES
--------------------------------------------------------------
CeroTouch Launcher es un launcher de Minecraft Java con dos
ventanas flotantes que puedes mover donde quieras:

  - Ventana negra : elige versión, loader (Vanilla, Fabric o
                    Quilt), memoria RAM y pulsa JUGAR.
  - Ventana blanca: tu skin, tus mods y un buscador de mods.

Descarga el juego, las librerías y Java por ti. No tienes que
instalar nada más de Minecraft.


REQUISITOS
--------------------------------------------------------------
  - Windows 10 u 11
  - Python 3 (gratis): https://www.python.org/downloads/windows/
    Al instalarlo, marca la casilla "Add python.exe to PATH".
  - Conexión a internet la primera vez
  - Unos 2 GB libres en disco


INSTALACIÓN EN 4 PASOS
--------------------------------------------------------------
1. Descarga los tres archivos y déjalos JUNTOS en una carpeta
   fija (por ejemplo, Documentos\CeroTouch):

       cerotouch_launcher.py
       launcher_core.py
       Iniciar_CeroTouch.bat

2. Haz doble clic en  Iniciar_CeroTouch.bat

3. Se abre una ventana de texto. Si falta algo, lo instala solo.
   Después te pregunta si quieres crear el acceso directo:

       [Y]  Sí : crea el acceso directo "CeroTouch Launcher"
                 en tu escritorio y en el menú Inicio, y abre
                 el launcher.
       [N]  No : no crea nada y el launcher no se abre.
                 Puedes volver a ejecutar el .bat cuando quieras.

4. Listo. Desde ahora abre CeroTouch Launcher con su icono del
   escritorio, como cualquier otra aplicación.

IMPORTANTE: no muevas la carpeta después de instalar. Si la
mueves, crea el acceso directo de nuevo (ver más abajo).


VENTAJAS DEL ACCESO DIRECTO
--------------------------------------------------------------
  * Se abre con un doble clic, como una app normal.
  * No aparece la ventana negra de consola.
  * Tiene su propio icono (un yin-yang) en el escritorio, en el
    menú Inicio y en la barra de tareas.
  * Lo puedes buscar escribiendo "CeroTouch" en el menú Inicio.
  * Puedes fijarlo: clic derecho sobre el icono y elige
    "Anclar a la barra de tareas" o "Anclar a Inicio".
  * Se instala una sola vez; no tienes que volver a usar el .bat.
  * Si lo borras o mueves la carpeta, se recrea con el botón del
    monitor que está junto a "Registro" en la ventana negra.


PRIMER USO
--------------------------------------------------------------
1. Escribe tu nombre de usuario (3 a 16 letras, números o _).
2. Elige loader y versión de Minecraft.
3. Elige la memoria RAM (el launcher solo ofrece lo que tu
   equipo puede dar).
4. Pulsa JUGAR. La primera vez tarda más porque descarga todo.

Sobre el nombre de usuario: el launcher funciona en modo
offline. El nombre es solo local, no inicia sesión con cuentas
de Microsoft ni sirve para servidores que exigen cuenta original.


SI ALGO FALLA
--------------------------------------------------------------
  - "No se puede ejecutar esta aplicación":
        el .bat está vacío; descárgalo de nuevo.
  - "No encuentro cerotouch_launcher.py":
        el .bat debe estar en la misma carpeta que los .py.
  - El acceso directo no abre nada:
        moviste la carpeta; créalo de nuevo con el botón del
        monitor o ejecutando otra vez el .bat.
  - Minecraft se cierra al iniciar:
        pulsa "Registro" en la ventana negra para ver el motivo.
  - Errores del propio launcher se guardan en:
        %APPDATA%\.cerotouch\errores.log
