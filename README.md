# CeroTouch-Launcher
Launcher de Minecraft Java con dos ventanas flotantes en estilo ying-yang. Elige versión, Vanilla, Fabric o Quilt, usa tu skin offline con visor 3D y gestiona mods por categorías, con buscador de Modrinth. Descarga Java y el juego solo, y crea su propio acceso directo. Hecho en Python + PyQt6. Modo offline, código visible.
